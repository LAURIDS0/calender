# Kalenderbygger

En ren statisk kalender-editor uden login, annoncer eller backend.

## Funktioner
- A3, A4, A5, A2, A1, Letter, Legal + custom mm-format
- Stående / liggende
- Dag, flere dage, uge, måned og helt år
- Valgfri startdato
- Mandag / søndag / lørdag som uge-start
- Flere kalender-sprog
- Helligdage fra Nager.Date for valgte land
- Egne begivenheder
- Ugenumre, månefaser, weekender, nabomåned-dage og noter
- Kasse, linje eller minimal dag-visning
- Live preview, zoom og tilpas
- Print / PDF via browserens printdialog
- Gemmer opsætning lokalt i browseren
- Eksport/import af JSON-opsætning

## Kør
Åbn `index.html` direkte i browseren eller host mappen som statiske filer.

Helligdagsfunktionen kræver internetforbindelse, fordi landets helligdage hentes fra Nager.Date. Resten af editoren fungerer lokalt.
